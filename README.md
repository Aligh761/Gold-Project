
# 💰 Currency & Gold Prices

A simple Android demo app that displays currency exchange rates and gold prices.

## ✨ Features

- 💵 Display currency exchange rates
- 🪙 Show gold prices
- 📱 Simple and user-friendly interface
- 🌐 Retrieve price data from an API
- ⚡ Lightweight and easy to use

## 🛠️ Built With

- **Kotlin** — Programming language
- **Android Studio** — Development environment
- **Retrofit** — API communication
- **JSON** — Data handling

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Internet connection

### Installation

1. Clone this repository:

   ```bash
   [git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git](https://github.com/Aligh761/Gold-Project.git)
   ```

2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Run the app on an Android device or emulator.

## 🎯 Purpose

This project was created as a demo to practice Android development and displaying data retrieved from an API.
